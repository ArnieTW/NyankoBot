Setup Page

Chat

Chat is the live message surface for enabled chat-capable connectors. It can be opened from Setup Home or through the external gateway URL.

Chat Feed

Use Chat to confirm that Twitch, Kick, or Streamer.bot events are arriving before connecting them to command triggers or overlay boxes. The unified feed shows timestamps, connector and platform cues, user badges, colored names when supplied, and rendered emotes. Unknown badges fall back to a readable initial when no badge image is available.

Messages and channel events

Chat shows regular messages alongside supported channel events. First messages are marked First words; messages generated by NyankoBot can show an Internal label. Reward redemptions can show the reward title, cost, status, and viewer input. Follow, subscription, gift, Bits, and Power-up lines appear when the connector supplies those events. Kick events use the same feed style when data is available.

A reply includes the original author and a short excerpt above the message. Shared chat origin and connector icons help identify where a message came from. The feed follows new messages when you are near the bottom; scroll up to read older items without being pulled back down.

Send, reply, and mention

  1. Choose All to send to visible chat connectors, or select one connector tab to target only that connection.
  2. Type a message. Enter @ plus a viewer name to open mention suggestions for the current tab. Use the arrow keys and Enter or Tab to insert a suggestion, or click it.
  3. Leave Send as bot if available on to use the bot account when supported. The broadcaster account is used when a bot account is unavailable.
  4. Select Send. The status reports how many targets succeeded or failed.

To reply, use a message's reply button. Chat switches to that message's connector and shows a reply preview with the original text. Send your response, or cancel the reply from the preview. Message deletion is available from a message row when the connector and account support it; inspect the status if deletion fails.

Platform Tabs

Chat is driven by enabled and connected connectors. If no messages appear, check the matching Connector first, then confirm that the account is connected and the connector is visible in All. Selecting its own tab still shows it when hidden from All. A reply and its send target always stay on the message's connector.

  • Use Chat to verify incoming messages.
  • Use Command Triggers to decide what NyankoBot does when chat commands or connector events arrive.
  • Use overlay boxes when those events should display text, media, TTS, or other sources on stream.
