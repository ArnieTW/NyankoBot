Setup Page

Chat

Chat is the live message surface for enabled chat-capable connectors. It can be opened from Setup Home or through the external gateway URL.

Chat Feed

The Chat page is useful for confirming that Twitch, Kick, or Streamer.bot chat events are arriving before you bind those messages to command triggers or overlay boxes. Messages use the user avatar as the primary image, with small connector/platform icons layered onto it.

UI areaWhat it means
AllShows messages from connectors that are visible in All. Hidden connectors are excluded from the All count and All send target list.
Connector tabsSwitches the visible filter locally without reloading the full message list.
Eye iconToggles whether that connector contributes messages to All.
Message listShows recent messages received by NyankoBot, oldest at the top and newest at the bottom.
InputSends a message through the selected connector. When All is selected, NyankoBot sends only through connectors currently visible in All.
Send as bot if availableUses the bot account when the connector has one, falling back according to connector capabilities.
Copy URLCopies the external gateway URL for opening Chat in a separate browser window.

Platform Tabs

Chat is driven by enabled and connected connectors. If no messages appear, check the matching Connector first, then confirm that the account is connected and the connector is not hidden from All.

  • Use Chat to verify incoming messages.
  • Use Command Triggers to decide what NyankoBot does when chat commands or connector events arrive.
  • Use overlay boxes when those events should display text, media, TTS, or other sources on stream.
