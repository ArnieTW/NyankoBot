Setup Examples

These examples describe common first automations using the current connector, trigger, action, and source workflow.

Show Chat Text On Stream

  1. Open Overlay Setup and create an overlay.
  2. Add a box and position it where chat text should appear.
  3. Add a Text source.
  4. Set the text to {{user.display}}: {{text}}.
  5. Add a chat-message trigger and leave Ignore commands enabled if commands should not appear.
  6. Save the overlay and open it in OBS as a browser source.

Play A Media Clip From A Command

  1. Create or select an overlay.
  2. Add a box sized for the media clip.
  3. Add a Media source using a file or URL.
  4. Use Timer mode so the clip hides after playback.
  5. Add a command trigger such as !hype.
  6. Save and test the command from chat.

Read A Message With TTS

  1. Enable a TTS model from TTS Setup.
  2. In Overlay Setup, add a TTS source.
  3. Select the first available voice or a cloned voice.
  4. Set Message to {{text}}. For command triggers, {{text}} is the command argument text after the command prefix is removed.
  5. Bind the box to a command trigger such as !tts.

Translate A Chat Message

  1. Add a Google or local provider from Translators.
  2. Create a command trigger such as !translate.
  3. Add a Translator action.
  4. Set the input text to {{text}}, choose Default, Auto Google, Auto NyankoBot, or a specific language mode, then store the result in an argument such as translatedText.
  5. Add a Send Message action or Text source that uses {{translatedText}}.

Trigger A Source From An Action

  1. Create or select an overlay and box.
  2. Add an action named Trigger Box Source.
  3. Select the overlay, choose a box or Stream Preview, then pick an existing source variation or configure a manual source with the same controls as Add Source.
  4. Choose timing such as Max Length, a fixed duration, or Toggle.
  5. Save the action so the command can fire that source without adding a normal box trigger binding.

Pick A Random Source

  1. Add multiple sources to a box.
  2. Set the box source trigger mode to Random.
  3. Bind a trigger to the box.
  4. Each trigger will choose one source, avoiding the previous choice when possible.

Use Trigger Tokens

Any field with the trigger-token help marker supports autocomplete. Type {{ to open suggestions, keep typing to filter, then choose a token.

TokenUse
{{user.display}}Viewer display name.
{{rawText}}Original text exactly as the trigger supplied it.
{{text}}Normalized text. For Command triggers this is the command argument text with the command prefix removed.
{{sanitizedText}}Text with links, emoji, and other noisy parts removed when NyankoBot can sanitize it.
{{message.text}}Message text path for payloads that expose a message object. Prefer the short {{text}} alias when available.
{{command.name}}Command name selected by Streamer.bot.
{{command.fullCommand}}Full command text, when Streamer.bot provides it.
{{command.counter}}Total command-use counter.
{{command.userCounter}}Command-use counter for the current viewer.
{{channel.platform}}Twitch, Kick, YouTube, or the platform supplied by the trigger.
{{argumentName}}A value created by Set Argument, Translator, random-list, connector request, or another action result.

Autocomplete is the safest way to insert tokens because NyankoBot stores the real token key while displaying a readable label chip.
