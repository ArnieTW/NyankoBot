Triggers

Platform Events

NyankoBot can start a command trigger or overlay binding from connected platform events. The available picker items depend on enabled connectors, their login permissions, and subscribed events.

Choose the right event

  1. Connect the platform under Connectors.
  2. In Command Triggers or an overlay's Binding Editor control, search by event name or category and select the event.
  3. Use hit rules or permission and cooldown settings when the event should run only for certain users or payloads.
  4. Save, cause a real event, and review trigger History if it does not run.

Use a NyankoBot Channel Reward binding for a shared reward definition. Use a generic Twitch Channel Points event for a platform reward lifecycle event or a reward that NyankoBot does not manage.

Twitch event families

FamilyExamples in the picker
Chat and peopleMessages, commands, first words, follows, subscriptions, gift subscriptions, raids, whispers, announcements, moderation, and user presence.
Channel PointsCustom reward redemption and status updates, automatic redemptions, reward created/updated/removed, and custom Power-up redemption.
Bits and engagementCheers, Bits use or Power-ups, polls, predictions, goals, Hype Trains, and shoutouts.
BroadcastStream online, offline, and metadata updates; ad break begin; and ad notification.
Guest StarSession begin/end, guest updates, and settings updates.

Ad Notification fires before the next scheduled ad using the lead time configured on that trigger source; the initial lead time is 10 minutes. It depends on Twitch schedule data being available to the connector.

Kick, OBS, Streamer.bot, and NyankoBot

  • Kick: chat and supported webhook events, including rewards and stream events when the connector supplies them.
  • OBS: events from the connected OBS WebSocket session.
  • Streamer.bot: subscribed raw events, commands, and action triggers. See Streamer.bot Connector.
  • NyankoBot: synthetic commands, first words, timers, manual triggers, and Stream Deck calls.

If an expected event is missing, check connector health and subscriptions first. A selected event cannot fire until its source connector is enabled and receiving it.
