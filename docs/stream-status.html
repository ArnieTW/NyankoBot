Stream Status

Use Stream Status to change the title and category on connected Twitch and Kick streams, with tags where a connector supports them. Open it from the Stream Status control in the Setup Home header.

Edit stream status

  1. Enable and connect a Twitch or Kick connector. Connected streams appear under Streams, with a Live, Offline, or Unknown indicator.
  2. Enter a Global stream title to fill the title for every listed stream, or edit each stream title separately.
  3. Search the Global stream category and select a result. The chooser shows categories available from your connectors and any saved category bindings. Review the category shown on each stream afterward.
  4. Add or remove stream tags on connectors that show a Stream tags row. The tag row is absent when the connector does not support it.
  5. Select Update streams. Every stream needs a nonempty title. Read the result message; individual streams can fail even when others update.

Edits stay in the page until you update streams. The unsaved-edits indicator means the displayed values are still a draft. Use Cancel Editing to restore the latest loaded values.

Map categories across platforms

A category name or ID can differ between Twitch and Kick. Open Settings → Category Bindings to save one named binding with the matching category for each connector.

  1. Select Add binding and give it a name you will recognize in the global category search.
  2. Search and select the category for each applicable connector. At least one connector category is required.
  3. Select Save binding. Back in Stream Status, choose that binding from the global category results and verify each stream's resolved category before updating.

Choosing an ordinary category result only fills streams for which that result has a connector mapping. A saved binding is useful when the two platforms use different names for the same game or topic.

If an update fails

  • If no streams appear, check that a Twitch or Kick connector is enabled and connected on Connectors.
  • If category search has no result, try the platform's category name and check Category Bindings. Select a result from the menu; typing alone does not choose a category.
  • If only some streams update, read the per-stream error shown after Update streams and check that connector's login and permissions.

Trigger actions can use the current saved or refreshed channel title and category through connector-scoped tokens.
