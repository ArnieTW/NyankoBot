Stream Status

Use Stream Status to change the title and category on connected Twitch and Kick streams, with tags where a connector supports them. Open it from the Stream Status control in the Setup Home header.

Edit stream status

  1. Enable and connect a Twitch or Kick connector. Connected streams appear under Streams, with a Live, Offline, or Unknown indicator.
  2. Enter a Global stream title to fill the title for every listed stream, or edit each stream title separately.
  3. Search the Global stream category and select a result. The chooser shows categories available from your connectors and any saved category bindings. Review the category shown on each stream afterward.
  4. Add or remove stream tags on connectors that show a Stream tags row. The tag row is absent when the connector does not support it.
  5. Select Update streams. Every stream needs a nonempty title. Read the result message; individual streams can fail even when others update.

Edits stay in the page until you update streams. The unsaved-edits indicator means the displayed values are still a draft. Use Cancel Editing to restore the latest loaded values.

Map categories across platforms

A Category Binding is one reusable label for categories that differ by platform or connector. For example, you can name a binding after a game and select its Twitch category and its Kick category separately. The mapping is saved for each connector; creating it does not change any live stream.

  1. Open Settings → Category Bindings, select Add binding, and give it a name you will recognize in Stream Status.
  2. Search and select the matching category in each connector row. Selecting a result matters: typed text alone does not save a category. At least one connector category is required.
  3. Select Save binding. Back in Stream Status, search for that name in Global → Stream category and select the result marked Binding. Its connector icons show which streams have mappings.
  4. Review each stream's category, especially any connector omitted from the binding, then select Update streams to apply the change.

The selection fills only streams with a mapping in that result; it does not invent a category for other connectors. You can edit or delete the saved binding in Settings. An ordinary category search result can also fill multiple streams when NyankoBot finds matching connector categories, but a binding lets you choose the exact pair yourself.

Use Stream Status in OBS or another browser

To open Stream Status as a password-protected gateway view, first enable External Access in Settings. On Setup Home, look beside Stream Status for the small copy icon with two overlapping rectangles. Select it to copy the gateway URL, then paste that URL into an OBS Custom Browser Dock or another application's web panel. Sign in with the gateway password.

For a second computer or phone, use the NyankoBot computer's reachable LAN address instead of localhost. The External Access guide explains the Host setting, OBS steps, and network precautions.

If an update fails

  • If no streams appear, check that a Twitch or Kick connector is enabled and connected on Connectors.
  • If category search has no result, try the platform's category name and check Category Bindings. Select a result from the menu; typing alone does not choose a category.
  • If only some streams update, read the per-stream error shown after Update streams and check that connector's login and permissions.

Trigger actions can use the current saved or refreshed channel title and category through connector-scoped tokens.
