Overlay editor

Bindings and Triggers

A binding connects one or more triggers to the items an overlay box displays. The current Binding editor groups its controls under Triggers, Sequencing, Subscriptions, and Items.

Open the Binding editor

  1. Open Overlay Setup, choose an overlay, and select the box you want to edit.
  2. Open its binding from the box inspector, or add a binding if the box does not have one.
  3. Rename the binding at the top if needed and choose its binding type. The collapsible sections below control activation and output.

You can edit an item, layered source, track, or track source in the sliding editor and return to Binding settings without opening a second dialog.

Triggers

Expand Triggers and select Add Trigger. The picker separates Command Triggers from Channel Rewards and shows connector events available to the current setup. Search names and categories; spaces, punctuation, underscores, and letter case are normalized in search.

You can assign multiple triggers to one binding. Review each selected trigger and its options before saving. Platform Events explains the main event families.

Choose a trigger source

SourceUse it for
Command TriggerA NyankoBot command or other saved trigger that can also run actions and cooldowns.
Channel RewardA NyankoBot-managed reward shared across supported connectors.
Connector eventTwitch, Kick, OBS, Streamer.bot, timer, Stream Deck, or another available event.

Generic chat bindings can ignore command-like messages or messages sent internally by NyankoBot. Raw event bindings can use hit rules to require matching event data.

Subscriptions

The Subscriptions section lists subscriptions associated with the binding. Expand it to inspect or add one when the chosen trigger requires connector event subscription behavior. If an event never reaches NyankoBot, also check the connector's own event subscription settings under Connectors.

Sequencing

Use Sequencing when a binding has multiple items. Add a default sequence for normal behavior, then add trigger-specific rows where a selected trigger needs a different order. Rows can be reordered, and a custom sequence can choose items using trigger data.

ChoiceEffect
SequenceAdvance through items in a chosen order.
RandomChoose from available items.
AllRun all available items where the binding type supports it.
CustomUse IF/Else rules and token values to choose items.

Items and custom cases

Expand Items and select Add Item to choose what the binding displays or plays. Media appears in a visual gallery; highlighting video or audio lets you preview it with sound. Open an item to edit its source or layered tracks in the sliding editor.

For a custom sequence, use IF/Else to compare incoming event data and choose an item. Type {{ in supported fields to insert a trigger token. Set an Else result for events that match no rule.

Save and test

  1. Check that the binding has at least one intended trigger and item.
  2. Save the binding and run a real or manual trigger.
  3. If nothing appears, inspect History, connector health, the binding's trigger options, and item timing.
