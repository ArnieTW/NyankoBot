Overlay editor

Bindings and Triggers

A binding is the unit that connects activation, playback, and content. Each box can hold bindings; each binding can have multiple triggers and items. The editor groups these under Triggers, Sequencing, Subscriptions, and Items.

Open the Binding editor

  1. Open Overlay Setup, choose an overlay, and select the box you want to edit.
  2. Open its binding from the box inspector, or add a binding if the box does not have one.
  3. Rename the binding at the top if needed and choose its binding type. The collapsible sections below control activation and output.

The box inspector lists saved bindings. Open a card with Edit to see its summary, or remove the binding there. The editor title has an Edit control for renaming and a binding type selector. Item, layered source, track, track source, and trigger editing slide into this same editor; use Binding settings to return.

Triggers

Expand Triggers and select Add Trigger. The picker has separate Command Trigger and Channel Rewards tabs. Search the saved trigger or reward by name, key, description, or category. Search ignores differences in spaces, punctuation, underscores, and letter case.

Create a connector event under Command Triggers first, then select that saved trigger here. One binding can hold several triggers. Each trigger row has Edit, remove, and playback controls.

Choose a trigger source

SourceUse it for
Command TriggerA saved NyankoBot trigger. Its source can be a chat command, connector event, timer, or other supported event, with its own actions, permissions, and cooldown.
Channel RewardA NyankoBot-managed reward shared across supported connectors.
Connector eventConfigure it as a Command Trigger source, save the trigger, then attach it to this binding.

Set playback per trigger: Max Length follows the content duration, Toggle changes visibility on each activation, and Custom uses a duration you enter. The initial position control can show a binding when the overlay first connects. For chat and raw event filtering, edit the source on the saved Command Trigger.

Subscriptions

Subscriptions watches a persistent variable key. Select Add Subscription and enter the key used by the binding. The row can be edited or removed later. Subscriptions use the default sequence when the binding runs; they are separate from connector event subscriptions configured under Connectors.

Sequencing

Sequencing becomes available after the binding has at least two items. Configure Default for normal behavior and subscriptions. Select Add Sequence to add a trigger-specific row, then choose which of this binding's triggers use it. Drag rows or use their move buttons to change their priority. If no assigned row selects an item, the default is the fallback.

ChoiceEffect
SequenceAdvance through items in a chosen order.
RandomChoose from available items.
All (as ready)Start available items independently, where the box allows All modes.
All (together)Start available items together, where the box allows All modes.
CustomUse IF/Else rules and token values to choose items.

Items and custom cases

Expand Items and select Add Item. Choose a saved source, search KLIPY, or create text, media, URL, or TTS content using the source controls. Saved items appear as gallery cards with type labels, previews, Edit, and remove. Highlighted video and audio previews can play with sound.

For a custom sequence, use IF/Else rules to choose an item from incoming event data. Type {{ in supported fields to insert a trigger token. Configure an Else item on the default row; an unmatched trigger-specific row continues to the next assigned row and then Default.

Save and test

  1. Add at least one item and a trigger or persistent variable subscription.
  2. Use Binding settings to return from an item or trigger editor, then close the binding editor. The overlay editor tracks the changed layout; save the overlay before leaving.
  3. Run a real event or a manual trigger. If nothing appears, inspect the saved trigger's History, connector health, playback mode, sequence assignment, and item timing.
