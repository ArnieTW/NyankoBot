Setup

Download & Install

Choose the Windows, Linux GUI, or Linux headless package from the latest GitHub Release, then open NyankoBot's local setup page.

Install Steps

  1. Download the package for your operating system from Downloads.
  2. Extract the package into a folder you control.
  3. On Windows run NyankoBot.exe. On Linux run NyankoBot-gui.sh or NyankoBot-headless.sh from the matching package.
  4. On Windows use the tray icon to open Setup Home. On Linux, open the local setup URL shown by the running app.
StepWhat to check
GitHub ReleasesUse the newest GitHub release package. The public site intentionally points users to GitHub releases instead of hosting separate release builds.
Extract packageUse a normal folder you control, not a temporary zip preview. This lets NyankoBot create local settings, model cache, overlay data, and logs beside its runtime data path.
Windows appNyankoBot.exe starts the tray process and local setup server. If Windows blocks first launch, allow the app only when the package came from the expected release.
Linux scriptsUse the GUI launcher for a desktop session or the headless launcher for a server session. The Linux packages are still testing builds.
Setup HomeUse the Windows tray menu or the local address printed by a Linux launch. The setup and overlay URLs use the configured host and port.

First Run

NyankoBot creates its local data and settings files when it starts. A fresh install should not require pre-existing overlay or TTS configuration files.

After first launch, continue to Quick Setup. That path connects a platform, creates one OBS overlay, and adds the first boxes inside it.

Setup Home

After launch, open Setup Home from the Windows tray or your Linux browser. This page is the entry point for the main setup areas; Chat and Stream Status also open from the header.

EntryUse it for
Overlay SetupCreate and edit the full-scene OBS overlay, boxes, sources, and trigger bindings.
ConnectorsCreate and monitor Streamer.bot, Twitch, and Kick connector instances. See Connectors.
Command TriggersBuild NyankoBot-owned triggers, action flows, cooldowns, and channel reward handling. See Command Triggers.
Channel RewardsCreate shared rewards and map them to Twitch or Kick connector instances. See Channel Rewards.
ChatWatch connector chat events while testing commands and overlay reactions. See Chat.
Streamer.bot ConnectorConnect NyankoBot to Streamer.bot, subscribe to event groups, and inspect bound triggers.
TTS SetupAdd Google TTS or local CosyVoice and Kokoro models, test voices, and configure TTS sources.
Stream StatusUpdate connected Twitch and Kick stream titles, categories, and supported tags. See Stream Status.
TranslatorsConfigure Google or local translation providers for trigger actions. See Translators.
StorageReview reusable source assets and cached source data when media or source references need checking. See Storage.
SettingsInspect app settings, update checks, and logs. See Settings.
