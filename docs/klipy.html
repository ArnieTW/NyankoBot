Overlay media

KLIPY Media

KLIPY supplies remote GIFs, stickers, clips, and memes inside the source browser. You can attach a result to a binding item without first uploading a local file.

Add KLIPY media to a binding

  1. Open Overlay Setup, select a box, and open or create a binding.
  2. Under Items, choose Add Item. In its source editor, choose the Defined Sources browser and expand KLIPY.
  3. Choose a media type, search or browse trending results, then select a result card. Review the selected preview and source settings before returning to Binding settings.
  4. Add a trigger, save the overlay, and test it in the overlay viewer or OBS.

The selected item keeps KLIPY provider details and a direct remote media URL. It does not become a local uploaded source. Remote URL media is loaded for the current session as needed.

Browse and filter

ControlWhat it does
GIFs / Stickers / Clips / MemesSwitch the KLIPY library. With an empty search, the browser shows trending results for that type.
Search KLIPYSearch the current media type; results update after a short typing pause.
PG / PG-13 / Mature / OffSet the content filter for browsing. PG-13 is the initial selection unless the browser has a saved choice or the installation supplies another default.
Results per pageChoose 8, 16, 24, 32, or 48 result cards. The browser remembers this choice.
Page controlsMove forward or back, or enter a page number. Changing search, type, filter, or page size returns to page 1.

Provider attribution and any advertisement cards are part of the KLIPY result display. Advertisement cards are identified as such and are separate from media choices.

If the library is unavailable

Configure and enable KLIPY to browse its library means the running installation is disabled or has no usable API key. KLIPY is an optional integration in the application configuration; the source browser itself has no key entry form. The status can also show Unavailable if a request fails. Check the app configuration and connection, then reopen the source browser.

The installation's appsettings.json contains a Klipy section. If you provide your own KLIPY API key there, set Enabled to true, add ApiKey to that section, and restart NyankoBot. The app also accepts a provisioned key from its configured worker. Keep the key private; the browser only needs the integration status and media results.

Saved local sources and uploads remain available without KLIPY. If a selected KLIPY item later fails to render, check its remote URL and the overlay viewer's connection; it is not stored as a permanent local media cache.
