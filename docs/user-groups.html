Settings

User Groups

Use Settings → Groups to organize viewers across connected platforms. The built-in Ignore group blocks its members from command triggers.

Create a group

  1. Open Settings, then the Groups tab.
  2. Select New group. Enter a name and optional description, then select Save group.
  3. Select the saved group in Group List to see its members. Use Refresh if connector user data has changed.

NyankoBot also has a default Ignore group. Users in Ignore are blocked from all command triggers, so check membership there when a viewer's commands never run.

Find and manage members

  1. Select the target group first.
  2. Under Find User, enter a username or login and select Search. Results come from available connector user data.
  3. Choose the correct platform user from the results and add them to the group.
  4. Use the selected group's member list to inspect users, maintain notes, or remove a member when their access changes.

When a search has no result, check that the platform connector is connected and has seen or cached the user. The same display name may belong to different platform accounts; check the connector identity before adding someone.

Use Ignore with command triggers

The Ignore group is a global block for Command Triggers. Remove a user from Ignore before testing their command. Use the trigger editor's separate platform role restriction and cooldown controls for roles such as moderator, VIP, follower, or subscriber.

After changing a trigger, test with a member account and review History if it does not fire.
