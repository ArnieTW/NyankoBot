Sources

Manage Sources

Manage Sources is the audit page for reusable source definitions, media previews, source usage, and cached files.

Defined Sources

Use this page when a reusable source needs to be checked outside the overlay editor. Sources are usually created from the Add Source Dialog, then reused by boxes inside overlays.

Column or controlWhat it means
RefreshReloads defined sources, overlay usage, and cache state from disk.
NameThe reusable source label shown in source pickers and source lists.
TypeThe source family, such as text, media, URL, or TTS.
BoxesShows how many overlay boxes reference the source. Click the count to inspect where it is used.
PreviewAvailable for media-like sources. Opens a floating preview so you can test the source without editing an overlay.
ActionsShows cleanup actions such as deleting cached media or removing a reusable source definition.

Usage

The usage popover answers the question: which overlays and boxes still depend on this source?

ControlUsage
Boxes countOpens the usage popover for that source.
Source usageLists the overlays and boxes that reference the selected source.
CloseCloses the floating usage panel and returns to the source table.

Check usage before deleting a source. Deleting a reusable source can leave existing boxes with local source data, but it removes the shared definition from future reuse.

Preview

The preview popover renders the selected source and exposes enough settings to confirm whether the source itself is healthy before blaming OBS or trigger bindings.

ControlWhat it does
PreviewOpens a floating preview for the selected source.
Regular / CachedSwitches between the original source URL and the cached file when both are available.
SettingsShows source metadata and render settings beside the preview.
Preview bodyDisplays the source as NyankoBot can render it: image, video, audio, URL, or other previewable media.

Cleanup

ActionEffect
Delete CacheRemoves the cached copy for a remote media source. The source definition remains, but NyankoBot may need to fetch the media again later.
Delete SourceDeletes the reusable source definition after confirmation. Check source usage first.
