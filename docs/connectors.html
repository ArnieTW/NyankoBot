Connectors

Connectors are the bridge between external tools, platforms, and NyankoBot. They feed chat, reward, OBS, command, and platform events into overlays and command triggers, and expose connector-specific actions.

Connector List

The Connectors page shows every configured connector, its current state, and whether it is enabled. Use Add Connector when you need another platform account or another integration instance. Connector setup screens are provided by the connector itself, so OBS, Twitch, Kick, and Streamer.bot do not all show the same fields.

UI areaWhat it means
Connector cardShows the connector icon, display name, internal type, connection state, and enabled toggle.
Connected / DisabledShows whether the connector runtime is currently active and usable by NyankoBot.
ToggleEnables or disables that connector without deleting its saved settings.
Add ConnectorCreates a new connector instance for a supported integration.
Clear CacheAppears on connectors with user/profile caches. It clears cached avatar/name/first-words data for that connector.

Connector Types

ConnectorUse it for
Streamer.botBridge existing Streamer.bot events, actions, commands, and raw events into NyankoBot.
TwitchRead Twitch chat, shared chat metadata, stream online/offline/update events, channel reward redemptions, and supported Twitch events.
KickRead Kick chat and supported Kick webhook events through the worker-backed connector path.
OBSConnect to OBS WebSocket for OBS events and actions such as refreshing NyankoBot browser-source pages.

Connector events can be used by Command Triggers, overlay box triggers, chat monitoring, reward workflows, and connector actions. Action fields are schema-driven and only show compatible connections for that action type.

After connecting Twitch or Kick, open Stream Status from the Setup Home header to update stream titles, categories, and supported tags.

Status Bar

The Setup Home header now shows connector health, connected overlay viewers, Chat, and Settings. Use it as the quick read on whether NyankoBot is connected before testing overlays.

  • Connectors shows how many enabled connectors are healthy and opens the compact connector status dropdown.
  • Viewers shows current viewer counts and opens the viewer list for connectors that provide names.
  • Chat opens the compact chat monitor from the setup header. The copy button beside it copies the external gateway URL.
  • Settings opens app settings and logs.
