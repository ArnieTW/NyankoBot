Command Triggers

Connector Action Catalog

These requests are available as named actions in the command trigger action picker when a compatible connector is configured. Twitch and Kick entries are marked implemented in their catalogs; OBS entries are exposed by the built-in OBS functionality catalog.

Using connector requests

  1. Connect the platform under Connectors. For Twitch and Kick, grant the listed account scopes.
  2. Open a Command Trigger, choose Add Action, and select the named request.
  3. Select a compatible connector instance and fill the required fields shown for that request. Fields vary by request and can use trigger tokens where the editor offers them.
  4. Set Store result as argument if later actions need the response. Use Save as persistent and Session only when the result must outlive the trigger run.
  5. Save and run the trigger. Inspect History and connector logs if a request fails; a platform can reject a request when the account lacks the needed role, permission, or resource.

The picker may show different entries depending on the connected instance. Catalog entries that are placeholders or marked unimplemented in source are omitted here. The internal Connector Request runner is described in the Action Reference.
