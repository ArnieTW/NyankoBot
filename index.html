Twitch and Kick bot for OBS stream automation

Create interactive Twitch and Kick streams with custom OBS overlays, automation, TTS, and viewer-triggered effects.

NyankoBot is a Twitch bot and Kick bot that lets you build interactive OBS browser-source overlays with text, images, video, audio, animations, and TTS. Trigger stream effects from chat commands, channel rewards, Streamer.bot events, platform events, and custom automation workflows.

OBS Overlay Studio

Create full-scene OBS browser-source overlays, then add triggered boxes for memes, alerts, captions, sound cues, videos, animations, images, and TTS moments.

Twitch, Kick and Streamer.bot Connectors

Connect Twitch, Kick, and Streamer.bot so NyankoBot can react to chat messages, commands, channel rewards, platform events, and custom stream automation triggers.

Stream Automation Triggers

Create chat commands, reward actions, cooldowns, waits, conditions, chat replies, overlay effects, media playback, TTS responses, and reusable automation chains.

Get Started

Download NyankoBot, run it on Windows, then open the setup page from the tray menu. Connect Twitch, Kick, or Streamer.bot, create an OBS browser-source overlay for your stream scene, add boxes for viewer-triggered effects, define chat commands and channel rewards, then copy the overlay URL into OBS.
